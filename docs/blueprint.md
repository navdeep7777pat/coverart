# **App Name**: Artify

## Core Features:

- Music Information Input: Input fields for song title and artist name to describe the music
- AI Cover Art Generation: Generative AI tool that analyzes the song title and artist name to create relevant cover art.
- Cover Art Display: Display generated cover art in a 1:1 aspect ratio.
- Image Download: Download the generated cover art as a JPG file.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to evoke creativity and musicality.
- Background color: Light lavender (#E6E8FA) to complement the primary color.
- Accent color: Electric purple (#BE4BDB) for interactive elements and highlights, creating a visually stimulating contrast.
- Modern and legible typography.
- Simple and intuitive icons for actions like 'Download' and 'Regenerate'.
- Subtle loading animations during cover art generation.
